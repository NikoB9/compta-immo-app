# Security policy

## Reporting a vulnerability

Please report security issues through GitHub's private vulnerability reporting feature when it is enabled for this repository. If that feature is unavailable, contact the repository maintainers privately using the contact method published in the repository profile. Do not disclose an unpatched vulnerability in a public issue or pull request.

## Protect private information

Never include real names, email addresses, property addresses, invoices, tax declarations, bank details, mandate scans, signature images, access tokens, database exports, backups or production logs in public issues, pull requests or test fixtures. Provide a minimal description and use fictional replacement values.

This policy applies to this public source repository. Production records and original documents belong in private runtime storage.
